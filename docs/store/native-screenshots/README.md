# Originali nativi / Native source images

32 PNG RGB IT/EN della build host corrente, prima della composizione promozionale.
VPShots riproduce i componenti JUCE reali con la demo sintetica inclusa, alimentata
in tempo reale. Il controllo ELAB./PROC. è OFF, come consigliato nella guida.
Le pagine acquisti usano stati/prezzi locali espliciti di VPPaywall, non transazioni.
Non sono catture di un dispositivo fisico né di un simulatore.

Le immagini finali da caricare sono in ../screenshots/, non in questa cartella.
Questi originali servono ai template cover.html e features.html in ../launch-art/.
Il motore audio non è stato cambiato durante questo allineamento grafico.
