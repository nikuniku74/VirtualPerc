# Dance grooveA loop sources

All source recordings used in this bank are released under Creative Commons Zero (CC0 1.0). The files in this directory are edited derivatives: two-bar excerpts/repetitions, pitch-locked time-stretched to the declared native BPM, peak-normalised to -6 dBFS, and exported as stereo 48 kHz/24-bit WAV.
